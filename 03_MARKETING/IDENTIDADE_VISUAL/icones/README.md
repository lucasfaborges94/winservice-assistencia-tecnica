# Ícones Winservice

Família de 15 ícones SVG, traço de 1,8 em grade de 24 × 24. O traço usa `currentColor` quando o SVG é embutido no HTML. Para uso como arquivo externo com cor definida pelo tema, aplique o SVG como `mask-image` e use `background-color: currentColor`.

Arquivos: `tema-sistema.svg`, `tema-claro.svg`, `tema-escuro.svg`, `ferramenta.svg`, `gota.svg`, `local.svg`, `conversa.svg`, `relogio.svg`, `escudo.svg`, `telefone.svg`, `verificar.svg`, `seta-direita.svg`, `vazamento.svg`, `vazao.svg`, `frio.svg`.

Use rótulo textual para ações. Ícones decorativos devem ter `aria-hidden="true"` no elemento que os contém.
